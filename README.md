# 🏥 Прогноз медицинских страховок (Medical Insurance Cost Prediction)

Этот проект представляет собой приложение машинного обучения, которое предсказывает ориентировочную стоимость медицинской страховки пациента на основе его персональных данных (возраст, пол, ИМТ, курение, наличие детей, регион).

В проекте реализован полный цикл:
1. Подготовка данных и обучение модели (`train.py`).
2. Сохранение обученной модели (Random Forest).
3. Веб-интерфейс на базе Gradio (`app.py`).
4. Базовые тесты (`tests/test_basic.py`).

---

## 🚀 Как запустить проект

Виртуальное окружение (`.venv`) уже находится в папке проекта. Следуйте инструкциям ниже для запуска.

### 1. Активация виртуального окружения

Откройте терминал в папке проекта и выполните команду активации:

**Для Linux/macOS:**
source .venv/bin/activate

**Для Windows (Командная строка):**
.venv\Scripts\activate.bat

**Для Windows (PowerShell):**
.venv\Scripts\Activate.ps1

*(Если потребуется, вы можете установить зависимости вручную с помощью `pip install -r requirements.txt`, но в готовом окружении они уже должны быть).*

### 2. Запуск пайплайна обучения (Опционально)

Если вы хотите заново обучить модель, построить графики ошибок и сохранить файл модели (`best_insurance_model.pkl`), выполните:

python train.py

*Скрипт выведет метрики (MAE) в консоль и сохранит график `error_plot.png`.*

### 3. Запуск веб-интерфейса

Чтобы запустить пользовательский интерфейс Gradio и протестировать модель вручную, выполните:

python app.py

После запуска в терминале появится локальная ссылка (например, `http://127.0.0.1:7860`). Откройте её в браузере.

### 4. Запуск тестов

Проект покрыт базовыми тестами с использованием `pytest`. Для проверки работоспособности выполните:

pytest

Тесты проверят корректность работы функции предсказания и успешность сборки интерфейса.

## 📂 Структура проекта

* `insurance.csv` — датасет с данными пациентов.
* `train.py` — скрипт обучения модели (подготовка данных, сравнение моделей, сохранение лучшей).
* `app.py` — веб-сервер с интерфейсом Gradio.
* `best_insurance_model.pkl` — сохраненная обученная модель.
* `requirements.txt` — список Python-зависимостей.
* `tests/` — папка с тестами.
